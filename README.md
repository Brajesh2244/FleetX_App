## 🌟 Core Features
- **EV Charging & Station Management:** Real-time charging station status, connector availability, power consumption metrics.
- **Smart Parking & Telematics:** Real-time slot allocation, QR-based entry/exit verification, and billing simulation.
- **Fleet Analytics:** Battery health indicators, driver assignment logs, vehicle servicing schedules, and fleet KPI cards.
- **Role-Based Admin Console:** Comprehensive dashboards for fleet supervisors and station operators.

## 📂 Architecture & Components
- `/web`: React + Vite web dashboard (deployed live on Vercel)
- `/backend`: Java Spring Boot microservice REST API with JWT security
- `/mobile`: Cross-platform Flutter mobile client for drivers and EV station customers
